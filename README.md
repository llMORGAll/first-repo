# CS 46B – Lab 12: Family Tree

**San José State University | CS 46B – Data Structures**

## Project Description

This lab implements a family tree in Java using tree nodes, recursion, and ArrayLists. The program reads the Baggins family tree from a text file, constructs the tree, and finds the most recent common ancestor of two family members.

## Project Files

- `src/trees/FamilyTree.java` – Implements the family tree and its methods.
- `src/trees/TreeException.java` – Handles exceptions related to the family tree.
- `BagginsFamilyTree.txt` – Contains the family relationships used by the program.

## Features

- Adds child nodes to the family tree.
- Searches for family members recursively.
- Collects ancestors of a given node.
- Finds the most recent common ancestor of two family members.
- Displays the family tree.

## Testing

The program compiled and ran successfully in VS Code.

**Test result:**

The most recent common ancestor of Bilbo and Frodo is Balbo.

## How to Run

Open the project in VS Code with Java support installed, run `FamilyTree.java`, and select `BagginsFamilyTree.txt` when prompted.
